## 🌟 Overview
**GFG × BENNETT: CODE RUSH** is a 3D endless coding runner built for high-energy campus events, coding club stalls, touchscreen kiosks, and hackathon showcases. 

Players sprint along the Bennett University server tracks, collecting memory bytes, dodging syntax crashes, activating DSA power-ups, and competing for the **Bennett Coding Champions** leaderboard.

---

## 🎮 Key Features

- **🏛 Official Bennett University × GFG Branding**:
  - Official high-definition Bennett University crest & GeeksforGeeks green logo.
  - Institutional blue, emerald green, and cyber arcade aesthetic.
  - Live campus high-score tracker ("Bennett Coding Champions").
- **⚡ DSA Power-Ups**:
  - 🛡 **Stack Shield**: Protects from 1 fatal runtime crash.
  - ⌕ **Binary Search**: Highlights the optimal O(log n) safe collision-free lane.
  - » **Queue Sprint**: FIFO supersonic boost + total invincibility.
  - # **Hash Map Magnet**: O(1) auto-attraction of memory bytes.
  - ♥ **Dynamic Programming**: Memoizes state granting +1 Extra Life.
- **☠ Bug Hazards**:
  - ∅ **Null Pointer Pit**: Abyss gap requiring timed jumps.
  - ▮ **Stack Overflow Wall**: Tall barriers demanding lane changes.
  - ∞ **Infinite Loop**: Fast repeating obstacle sequences.
  - ☁ **Memory Leak Fog**: Reduced vision challenge.
  - ±1 **Off-by-One Barrier**: Precise lane transitions.
  - ⛩ **Boss Gate**: Runtime error clear gates every 1,000m.
- **★ Algorithm Fever**:
  - Chain 3 syntax tokens (`{ }`, `[ ]`, `< >`) in a row to trigger 8 seconds of 3x Bytes and double score!
- **🎪 Stall & Kiosk Optimization**:
  - **PLAY NOW / START RUN** stall button.
  - Fullscreen toggle (⛶) for large monitors and kiosk setups.
  - On-screen touch D-Pad / buttons for touchscreen kiosks.
  - Instant 1-click **NEXT CODER** transition for stall queues.
  - Integrated QR code for club registration and social links.

## 🚀 How to Run Locally

You can run the arcade simply by opening `index.html` in any modern web browser or serving it via a local static server:

```bash
# Python HTTP Server
python -m http.server 8080

# Or Node npx serve
npx serve .
```

Then visit `http://localhost:8080` in your browser.
